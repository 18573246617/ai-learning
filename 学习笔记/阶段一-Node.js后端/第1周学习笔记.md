## 2. TypeScript 基础（够用就行）

### 2.1 interface（接口）：描述对象长什么样

```ts
interface User {
  id: number
  name: string
  email?: string   // 问号 = 可选
}

const user: User = { id: 1, name: "小明" }
```

### 2.2 type（类型别名）：给类型起名字、组合类型

```ts
type ID = string | number

type Status = "todo" | "doing" | "done"
// 联合类型：只能取这三个值之一
```

### 2.3 泛型：让函数支持多种类型

```ts
function first<T>(arr: T[]): T | undefined {
  return arr[0]
}

const n = first([1, 2, 3])    // n 是 number
const s = first(["a", "b"])   // s 是 string
```

### 2.4 类型推断：能不写就不写

```ts
let count = 0          // TS 自动推断为 number
const name = "Node"    // 推断为 "Node"
```

> 心法：interface 描述对象，type 用来组合类型，泛型用在“函数和多种类型打交道”的地方。第 1 周会这三个就够。

## 3. ESM 模块（import / export）

在 `package.json` 里加上 `"type": "module"`，然后就可以用 import：

```ts
// src/utils.ts
export function formatTime(d: Date): string {
  return d.toISOString()
}

// src/index.ts
import { formatTime } from "./utils.js"   // 注意：TS 里也写 .js 后缀
console.log(formatTime(new Date()))
```

## 4. 事件循环（面试必问，本周能说出执行顺序即可）

Node 是单线程，靠“事件循环”排队干活。执行顺序：

1. 同步代码：先执行
2. 微任务（`Promise.then` / `queueMicrotask`）：同步代码之后、宏任务之前
3. 宏任务（`setTimeout` / `setInterval` / I/O）：最后执行

```ts
console.log("1")                                  // 同步
setTimeout(() => console.log("2"), 0)             // 宏任务
Promise.resolve().then(() => console.log("3"))    // 微任务
console.log("4")                                  // 同步

// 输出顺序：1 → 4 → 3 → 2
```

记忆口诀：**先同步，再微任务，最后宏任务**。

## 5. 用 Node 原生 http 写 API（本周产出）

不用框架，先理解服务器本质：收到请求 → 返回响应。

```ts
// src/server.ts
import { createServer } from "node:http"

const server = createServer((req, res) => {
  res.writeHead(200, {
    "Content-Type": "application/json; charset=utf-8",
  })
  res.end(JSON.stringify({
    message: "Hello API",
    time: new Date().toISOString(),
  }))
})

server.listen(3000, () => {
  console.log("服务已启动: http://localhost:3000")
})
```

运行：

```powershell
npx tsx src/server.ts
```

浏览器打开 http://localhost:3000 能看到 JSON，就成功了。

### 进阶小挑战：按路径返回不同内容

```ts
const server = createServer((req, res) => {
```

## 7. 常见坑

1. `tsx` 提示找不到 → 用 `npx tsx`，或确认已在项目里 `pnpm add -D typescript tsx`
2. 端口被占用报 `EADDRINUSE` → 换一个端口，或关掉占用端口的旧进程
3. import 路径写成 `./utils.ts` 报错 → 改成 `./utils.js`（TypeScript 的模块解析规则）
4. 浏览器访问出现乱码 → 检查响应头是否设置了 `charset=utf-8`

## 8. 本周复盘问题（能答上来就过关）

- 微任务和宏任务谁先执行？为什么？
  微任务：Promise.then  queueMicrotask  process.nextTick 
  宏任务: setTimeout  setInterval  ,I/O和http请求

  先执行同步代码 → 清空微任务队列 → 取出第一个宏任务执行 → 执行该宏任务产生的微任务 → 循环直到宏任务队列都执行完

- interface 和 type 有什么区别？（一句话说清即可）
   1.interface可以进行多次定义 每次定义都是继承之前的
   2.interface不能定义基础数据类型还有 元组
   3.type不能同名
- 为什么 Node 能“同时”处理很多请求？
  Node.js 虽然是单线程，但基于事件驱动 + 非阻塞 I/O 模型，遇到 I/O 操作（文件读取、HTTP 请求等）不会阻塞主线程，而是交给底层 libuv 线程池异步处理，完成后通过回调加入事件队列，从而能"同时"处理大量并发请求。

- 你的服务器返回的是什么格式？响应头 Content-Type 是什么？

    响应头：'Content-Type': 'application/json; charset=utf-8'
    返回格式：JSON 格式，如 { data: 'Hello World!', message: '响应成功' }
