## 七、学习方法约定（重要）

- 每周：只给**学习笔记 + 练习要求**，不给成品代码；卡住 15 分钟以上再要提示
- SQL / RAG 练习没有标准答案：能跑出预期结果、每句能解释就算过
- 学习者特点：动手能力强、概念理解快、会主动做超纲探索；但**收尾习惯弱**——脚本常留语法错误、跑不通就往后走、清单会提前打勾、改动长期不提交
- 每周要盯"能跑通 + 已提交"，**WIP（未收尾项）不超过 2 个**

### 每周收尾硬标准

1. 能跑通：一条命令复现
2. 已提交：至少 1 次 commit，message 写清范围
3. 有笔记：概念 + 踩坑 + 面试问答
4. 有演示：截图 / 录屏 / `curl` 输出进 README
5. WIP ≤ 2：超了先清账再学新的
6. 周日 30 分钟复盘：本周产出 / 欠账 / 下周计划
